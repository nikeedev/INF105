# Hvofor linux i INF105
* Unix design: one toll has one job, composable

* 1984: GNU project (GNU's not Unix) -> åpne userspace tools: shell, coreutils, binutils, GCC compiler ...
* 1991: Linux kernel -> åpent OS

* Kunne også brukt FreeBSD / NetBSD / OpenBSD

# GNU - GNU's not Unix
* 1978: MIT AI lab får en ny laser printer, med lukket programvare
* ikke synlig til terminal-brukere når *paper jam* må fikses
* NDA for å vise frem koden
* 1984: GNU project -> åpent programvare, på fortsatt lukket UNIX
* 1991: Linux kernel: åpen implementering av et UNIX-system

# Creativ Commons
* Public domain / CC0 - ingen begrensninger
* **CC-BY** - forfatteren må nevnes
* **CC-BY-SA - share-alike - kan bare publiseres under lignende lisens (copyleft)** <- GNU (share-alike, copyleft)
* CC-NC - begrenset til ikke-kommersiell bruk
* CC-ND - no derivatives - ingen endringer
