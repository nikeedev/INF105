# UDP, TCP og IP

Vi er på lag 4, transport layer.

---
Network layer (layer 3) sender pakker mellom 2 enheter

En enhet kan ha mange applications i App layer (layer 5)

Transport layr er mellomleddet som gjør dette mulig, sender segmetns mellom 2 prosseser som kjører på enhetene:
 * enklest: UDP (RFC 768)

Transport layer også skal sikre pålitelig kommunikasjon:
 * TCP
